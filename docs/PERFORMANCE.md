# Render measurement

The reference is Apple M4, macOS arm64, Godot 4.5.1, Metal Forward Mobile, 1440 by 900, 4x MSAA, walking shadows at 140 m and a 4096 atlas.

The numerical generation is `8f7ed4ee574d61735e3ba679b9e712b3e67dc8c0a1fe496d43a151724f5b71d8`, from build `f75347b772fd` at model source commit `18f456de029bb528f23bd38a9f90125bcbb48bea`. The runtime source commit is `5872c121c5513798124e2bbbdf719ab28ec99592`. `evidence/forest-runtime-equivalence.json` authenticates unchanged model sources, physical inputs and checked artifacts, while separately identifying the display submission revision and asset metadata correction. The baseline is the previously published surface package `b2b3d24fd7a0`.


The identical work-only native harness runs in ABBA order after model builds, tests and editor imports finish. Each run captures nine fixed views, then 60 warmup and 120 moving-camera samples. Every measured sample advances exactly one drawn frame. A common authored fixture locks weather, epoch and the physical sun vector; it normalizes the old sun convention in memory without changing either package. This compares the releases under shared forcing, not unchanged as-shipped default lighting. Requested values are independently checked, then checked for drift over all captures and moving frames; input callbacks and external readers are disabled. Tree wind is disabled, while shader TIME and particles remain animated. Vsync is disabled by request; wall time includes presentation and the common forcing-verification overhead. The GPU monitor is unavailable. Desktop applications remain uncontrolled; these are not isolated GPU measurements. Original receipts retain their full inventories and global status. Runtime comparisons exclude exactly `dashboard/build_data.py`, an unbundled dashboard generator outside the numerical source-hash roots; its observed hash and any global staleness remain explicit. All included source, fixture and output hashes remain strict.

The runtime retains immutable source Multimeshes and fills a separate visible prefix for near/middle LOD submission. It selects the same per-tree center-distance interval as the shader, expanded by a 2 m guard, and refreshes after more than 1 m of camera movement or a camera change. Far impostors and all source instances remain available. No view-frustum filter removes off-screen shadow casters. The existing shader still controls the final LOD selection and complementary transition.

The source arrays contain 572,085 near/middle instance records. Retaining 20-float records plus three-float centers accounts for 52,631,820 bytes of CPU data payload; cloned 20-float GPU instance buffers account for 45,766,800 bytes of additional GPU payload. Retained selection indices add up to 2,288,340 bytes. These are format-based payload estimates, excluding allocator, resource, temporary-array and driver overhead; they are not measured total resident memory. Compaction trades those allocations and intermittent CPU selection/upload work for fewer submitted instances. The validator records update time and changed slots per tested position; these observations are not a whole-session CPU bound.

The uncompacted regression remains in `evidence/forest-render-pairs-uncompacted.json` and its raw capture directory. The intermediate pre-attachment run also remains historical; its B1/B2 initial-sun discrepancy prevents a causal performance interpretation. The final ABBA table above measures the adopted runtime. These are different experiments and are retained separately.


The retained acceptance target is median <= 33.4 ms and p95 <= 50 ms. Each run's explicit target result is in `evidence/forest-render-pairs.json`; no 60 fps claim is made. Earlier surface measurements remain in `evidence/surface-render-pairs.json`. An initial baseline attempt lacked its Godot class cache and timed out without samples; its failed receipt is retained and excluded from this table.

All 63,565 trees, 159,157 residual-canopy cells, existing render distances, shadows and antialiasing remain enabled. The complete adopted runtime is measured by the ABBA results above. At the original model/source snapshot, saved tree bindings passed 2,758,746 native checks over 22,254 batches and a capacity of 635,650 LOD instances. The equivalence proof preserves those baked inputs; this historical run is distinct from the final runtime compaction and canopy checks. That capacity describes the immutable baked records; it is not the number submitted after runtime compaction. Selection and source-retention checks do not establish endpoint image fidelity.

Final raw tree endpoint budgets pass 34 of 96 comparisons: 8/32 at 18 m, 8/32 at 65 m and 18/32 at 180 m. The remaining 62 failures and all raw captures remain public. Far billboard brightness differs from dynamically lit meshes. Dithering does not turn mismatched endpoints into a visual pass. Authored support dimensions and bough orientations have unknown uncertainty; residual cells are not inferred measured stems. Visible support is inspected in native captures at eight azimuths and three world views; source contact checks alone do not establish perceptual grounding. Residual supports and foliage preserve the existing no-shadow policy; field botanical acceptance and other renderer backends are not tested. Some residual source cells retain long authored bare stems below narrow, shallow crowns; the source cells do not resolve measured local branch form or additional stem counts. Final canopy attachment checks are recorded in `evidence/canopy-visible-attachments.json`.

Color mipmaps are filtered offline in linear light, with original level-zero pixels and the same per-texture RGBA8 mip layout. Eight buffers add 111,848,096 distribution bytes. The added forest material layers increase texture storage; unchanged sampler count does not imply unchanged total GPU memory. Mixed forest pixels add up to four texture reads, and the spring apron adds two detail reads. Four cloud density samples bound atmospheric work. These costs and structural savings are distinct from measured frame time.

Scientific claims remain unaccepted. Ground-cover abundance, crown envelopes, ring widths, terrace relief and rainbow occurrence frequency are authored or uncalibrated. Previous deer/badger deformation and textured mesh-reduction acceptance gaps remain open. Other platforms, native executable exports and whole-world live-service timing are untested.

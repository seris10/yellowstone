### A. Simulation Parameter Mapping
State the exact module, file, and variable structures:

### B. Parameter Provenance and Status (binding per AGENTS.md)
- `run_mode`: `illustrative` / `scenario` / `hindcast` / `observed_replay`. `forecast` refused.
- `status`: `illustrative` unless locked-final evaluation window exists. Both seed claims `not_yet_accepted` until then.
- `parameter_provenance`: source filenames, SHA references, `code_rev`, `units`, `contract_version: "0.1.0"`, `world_id: "yellowstone_midway"`.
- Unknown parameter uncertainty stays `unknown`; do not invent distributions. `t_uilt_c` and `t_refuge_c` must be cited directly, not interpolated without source.

### C. Validation Criteria (observable behaviors per M06)
- No trout path through `pool_1034_0` / `pool_1030_0` (`check_trout_clear_of_pools()` must pass).
- High-T reach (`t_c` near `t_uilt_c`) -> `hold_seconds` increases, `walk_mps` decreases; cold tributary -> faster movement.
- `refuge_map.png` shows nearest cold tributary / shaded bank selection consistent with thermal gradient.
- `build` (`pytest`) green; `audit_provenance` passes; `derived/<build-id>/` artifacts carry complete provenance.

### D. Thermal, Suitability, and Behavioral Equation Parameters
Deliver in the exact form used by `thermal_performance()` and `suitability()`:
- Thermal performance: `t_opt_lo_c`, `t_opt_hi_c`, `t_feed_zero_c`, `t_refuge_c`, `t_uilt_c` (numeric, °C, with source citations).
- Suitability weights: `wf` (food), `wc` (cover), `wt` (thermal penalty coefficient), `wv` (velocity sensitivity), `wd` (depth sensitivity); velocity/depth reference values (`VELOCITY_OPT_MPS`, `VELOCITY_TOL_MPS`, `DEPTH_REF_M`).
- Temperature penalty function `φ(Ti)`: shape / formula or tabular values; `refuge_drive` calculation input.
- Behavioral / refuge: `refuge_selection` rules (nearest cold tributary / shaded bank); `lateral_offset_m` behavior; seasonal adaptation parameters (`yellowstone_specific.behavioral_adaptations`).
- Population dynamics (`update_trout` / `update_species`): `behavioral_params`, `yellowstone_adaptations`, `population_factor`, `movement` (`_calculate_yearly_yellowstone_movement`).
- Competition matrix (`YELLOWSTONE_COMPETITION_MATRIX`): `competitors`, `predators`, `prey`, `competition_factor`, `ecological_impact`.

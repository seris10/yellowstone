# Phase E: Substrate Chemistry and Geochemical Guardrail (Scientific Report)

## Deliverable
A single markdown report defining substrate rules (silica sinter for Midway, travertine for Mammoth reference), fluid chemistry relationships, and the guardrail preventing future basin designs from misapplying substrate chemistry.

## Equations and Relationships
- Substrate classification: silica (SiO₂) sinter (siliceous, Midway) vs calcite (CaCO₃) travertine (calcium-carbonate, Mammoth reference only).
- Fluid chemistry: thermal water chemistry correlates with substrate mineralogy.
- Guardrail: any future pool/apron design must reference substrate type before pigment/color parameter selection.

## Report Sections
1. Substrate chemistry measurements (Midway silica, Mammoth travertine) with primary source citations.
2. Substrate rules registry format (type, fluid chemistry, mineral composition, reference basins).
3. Integration: substrate rules constrain pool shell design, apron eligibility, pigment band definitions; must not recolor existing thermal areas.
4. Validation: substrate import verified; no misapplication; provenance complete.

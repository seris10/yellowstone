# Existing toolchain quality

Source: Yellowstone existing toolchain quality audit, reviewed revision `9f81c3c873a45bb974af78cd1d58a0e90b9b0d1c`.

| Finding | Owner and boundary | Required evidence |
|---|---|---|
| QA-01 | Calibration free/frozen parameters and serialized model. | Fixed multiplier, low-flow bounds, reproducible final metrics, explicit optimizer termination. |
| QA-02 | Observation eligibility and actual fitted residual Jacobian. | Separate available, eligible, estimated and locally conditioned states; confounded negative control. |
| QA-03 | Numerical candidate selection and uncertainty membership. | Invalid candidates excluded, forward runs rechecked, fallback and insufficient ensembles explicit. |
| QA-04 | Analysis weather and authoritative scenario time. | Absolute epoch, local hour and elapsed time select the same instant; out-of-window refusal. |
| QA-05 | Contact calibration and resolved animation controls. | Complete engine-specific phases affect analytic and serialized bird/mammal walking. |
| QA-06 | Serialized animation validation and command status. | Required geometry, skin and clip failures return nonzero with a structured failed report. |
| QA-07 | Production source, reviewed rig, controls and exported surface. | Hash-bound review inputs, deformation gates, surface contact and target-engine evidence. |
| QA-08 | Body/foot immersion and hydrodynamic forces. | Dry forces vanish, gravity remains, wet drag opposes relative motion, floating equilibrium persists. |
| QA-09 | Actual fish ground motion and water-relative speed. | Signed upstream/downstream/drift/holding and target-arrival controls, explicit animation clock policy. |
| QA-10 | Canonical tree interchange and legacy adapters. | Both writers share a reader; old layouts migrate without losing evidence; unknown versions refuse. |
| QA-11 | Selected tree graph and final render-space geometry. | Parameter-to-GLB propagation, source graph identity, transforms and final attachment checks. |
| QA-12 | Source/display distributions and existing LOD boundaries. | Explicit artistic policy, per-tree silhouette traits, measured screen-space budget and actual captures. |
| QA-13 | Population dataset/model/base identity and exported variant. | Recoverable statistical lineage, reference mismatch refusal, regenerated deformation checks. |
| QA-14 | Installed documented command surface. | Supported help and fixture commands work outside the checkout; compatibility alias remains thin. |
| QA-15 | Original mesh, staged derivative and hard triangle cap. | Empty/over-budget rejection, reimport verification, source/output hashes, accepted derivative preserved. |

Numerical verification, geometric review, human visual acceptance and biological validation remain separate. Synthetic fixtures do not establish species accuracy. Existing original meshes, textures, source measurements, stable IDs, authored placements and completed historical builds remain preserved. Current execution evidence is source/fixture bound; changing implementation invalidates earlier current-status claims.

## Scientific validity flags
- live replay/surface_flux.py:41 hard-codes `SITE_PRESSURE_KPA = 77.8` while microclimate.py:11 computes ~77.3959; the two can drift and shortwave/longwave/humidity use different air density.
- live replay/surface_flux.py:70-75 uses `(1 + 0.22*cloud**2)` as a fixed cloud factor without labeling as uncalibrated in the output.
- live replay/surface_flux.py:45-47 Magnus formula is applied to any finite temperature with no domain check; sub-zero F values near -243.04 C produce a singularity.
- live replay/surface_flux.py:101 silently clamps wind to 0.5 m/s on the dataclass, so calm observations are indistinguishable from the imposed floor downstream (budget diagnostics, provenance).

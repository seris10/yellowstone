## Scientific validity flags
- The dispersion-enabled FiPy case now exercises the DiffusionTerm the production solver can carry; FiPy and the hand-rolled River agree to within sub-C at 60 cells for the synthetic 2.5 m2/s coefficient. The convection matrix is still shared first-order upwind, so a convection-side independent reference remains an open item.
- Reference datetime defaults to 1970-01-01 UTC when `wall_time` is absent from the first frame. A build that forgets to seed `wall_time` will produce a technically CF-conformant file whose time axis disagrees with the solver clock. The fix doc's Finding 3 (claims-side gate re-reading `cell_ids[0]` and `times_s[0] == 0.0`) covers this once E1 lands it; until then the time axis trust needs the caller to supply `wall_time` on frame[0].
- plume_field.json (fixes-33 #6, fixes-39 #7) and geochemistry.json (fixes-33 #5, fixes-39 #8) now land on the publish side as data sidecars with schema id, units, status, and provenance. The plume uses replay.plume2d.solve_steady, the same illustrative first-order upwind + Fischer dispersion model that renders plume_map.png; status is illustrative. Geochemistry writes per-cell quartz-equilibrium silica (Fournier 1977 no-steam-loss) from the last replay frame; without SiO2 observations, every row carries silica_saturation_index=null and flag=no_observation. The couplings into the foodweb and insect compartments stay proposed per fixes-33 items 5 and 6; this landing only reaches Godot.

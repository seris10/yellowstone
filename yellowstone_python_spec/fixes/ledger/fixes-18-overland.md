## Scientific validity flags
- live overland_provider.py:65 uses the rational method with no infiltration, antecedent wetness, lag, or baseflow; it is labeled synthetic but is wired into the river as upstream boundary via river_world (test_upstream_discharge_mean_drives_boundary).
- live overland_flow.py:173 uses `open_edges=()`, so the hydrosim run cannot ever produce outflow regardless of rain -- the "no runoff signal" assertion in tests/test_catchment_runoff.py:124-131 only verifies that closed domain stays closed.
- live overland_provider.py:112 picks the lowest-elevation cell as the drainage outlet after closing every edge; on a tilted plane this is a boundary corner surrounded by closed edges and drains nothing physical.
- Downloads `route_linear_reservoir` (overland_provider.py:96-118) uses `-expm1(-dt/tau)`, which is the exact release fraction over the step and preserves volume -- correct, but `tau_s` is still authored.
- Downloads provider still ignores snowmelt, baseflow, impervious cover; the status label stays "synthetic_catchment_predicted_not_validated".

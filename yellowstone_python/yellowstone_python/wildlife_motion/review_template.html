Fit the rig to the animal.

Drag a joint in any view. The third coordinate stays fixed. Inspect feet, knee/elbow bend direction, shoulder and hip pivots, head and tail. These are animation landmarks, not evidence that the hidden skeleton has been measured.

A folded-wing bird cannot fly correctly just by rotating this rig. Only set spread wings when the mesh actually contains the open wings and flight feathers.

Offline by design. No uploads, requests, accounts, or external libraries. Save the JSON and pass it to --rig. The source SHA256 prevents accidental reuse on another mesh. Rerun weight generation and numerical validation after editing.

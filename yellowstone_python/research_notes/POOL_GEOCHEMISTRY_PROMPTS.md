# Phase C: Pool Geometry, Thermal Profiles, and Substrate Chemistry (Scientific Report)

## Deliverable
A single markdown report covering bathymetry, thermal profile science, pigment band relationships, pool shell geometry, apron exclusion, and substrate rules (silica sinter vs travertine) as scientific constraints on simulation modeling.

## Equations and Relationships
- Radial temperature: T(r) mapped from center to edge; no universal temperature-to-color equation exists — pigment bands depend on temperature + depth + substrate + light independently.
- Plume profile: T(x) = Ta + (T0 − Ta)·exp(−he·b·x/(ρ·cp·Q))
- Thermal exclusions: pool temperature defines zones excluded from uniform snow cover and vegetation suitability.
- Substrate guardrail: silica sinter (Midway) vs travertine/calcite (Mammoth reference); future basins must reference substrate type before recoloring.

## Report Sections
1. Bathymetry measurements (Grand Prismatic >37 m, Excelsior 61×91 m crater) — unmeasured; labeled illustrative.
2. Thermal profiles (center/edge temperatures, radial gradient) — measurement sources, illustrative status.
3. Pigment band parameters (color stops) — temperature/depth/substrate/light relationship without universal equation.
4. Pool shell geometry (center, radii, shelf depth, rim, outflow) — authored vs surveyed.
5. Apron mask definition (hydrothermal ground vs vegetation eligibility) — exclusion rules.
6. Substrate rules: silica sinter (Midway), travertine (Mammoth reference); chemical composition; guardrail against future misapplication.

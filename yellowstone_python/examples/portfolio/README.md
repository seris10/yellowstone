# Small Yellowstone examples

Run these scripts in the Yellowstone Python environment with a new output directory. All inputs are synthetic; no network access is needed.

- `river_checks.py --out DIRECTORY` writes numerical checks and a refinement plot.
- `analysis_store.py --out DIRECTORY` writes a SQLite fixture and four query comparisons.
- `evidence_checks.py --out DIRECTORY` demonstrates source and output change detection.

See [the examples guide](../../../docs/examples.md) for commands and details. Matplotlib is required for the river plot.
